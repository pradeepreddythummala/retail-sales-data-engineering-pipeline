# Retail Sales Data Engineering Pipeline

A complete data engineering and analytics project that processes retail sales data using Python, SQL, PostgreSQL, and Power BI.

## 📌 Project Overview

This project demonstrates an end-to-end retail data pipeline starting from raw retail transaction data and ending with an interactive Power BI dashboard.

The pipeline includes:

- Data profiling
- Data cleaning
- Data transformation
- Data loading
- SQL database design
- SQL views and analysis
- Power BI dashboard development

## 📊 Key Results

The analysis and Power BI dashboard provide insights into:

- Top-performing products
- Return activity
- Yearly revenue performance
- Customer and quantity metrics
